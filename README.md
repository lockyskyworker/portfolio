# Lockey Skyworker - Portfolio Website

A modern, responsive portfolio website showcasing projects and expertise in security and AI development.

## Features

- **Responsive Design**: Fully responsive layout that works on all devices
- **Modern UI**: Clean and professional design with gradient accents
- **Smooth Animations**: Scroll animations and hover effects for better UX
- **Project Showcase**: Grid layout displaying featured projects with descriptions
- **Skills Section**: Organized skills and expertise categorized by topic
- **Contact Form**: Functional contact section for visitors to reach out
- **Social Links**: Direct links to social media and professional profiles
- **Performance**: Lightweight and fast-loading implementation

## Sections

1. **Navigation** - Sticky header with smooth scrolling navigation
2. **Hero Section** - Eye-catching introduction with call-to-action buttons
3. **About** - Overview of background and expertise with statistics
4. **Projects** - Featured portfolio projects with links to GitHub repositories
5. **Skills** - Categorized technical skills and expertise areas
6. **Contact** - Contact information and message form
7. **Social Links** - Links to social media profiles

## Projects Included

- **AI Security Series** - Comprehensive guide on securing AI systems
- **GitHub Onboarding Workshop** - Interactive GitHub learning resource
- **Secure Code Patterns** - Security best practices and patterns
- **AI Security Tools** - Tools and utilities for AI model security
- **Cryptography Essentials** - Cryptographic principles with implementations
- **Infrastructure Security** - Cloud and DevSecOps best practices

## Technical Stack

- **HTML5** - Semantic markup
- **CSS3** - Modern styling with CSS Grid and Flexbox
- **JavaScript (Vanilla)** - Interactive features without dependencies
- **Font Awesome** - Icon library for visual elements

## Customization

To customize this portfolio for your needs:

1. **Update Personal Information**
   - Edit the name "Lockey Skyworker" throughout
   - Update the subtitle and description
   - Modify email and contact details

2. **Add Your Projects**
   - Update project titles and descriptions
   - Replace project links with your own GitHub repositories
   - Modify gradient colors in project cards

3. **Update Skills**
   - Add or remove skills in the Skills section
   - Customize skill categories as needed

4. **Social Links**
   - Update social media URLs
   - Add or remove social profiles as needed

5. **Styling**
   - Modify CSS variables in `styles.css` to change colors
   - Adjust fonts and sizes for your preferences
   - Update breakpoints for different device sizes

## Color Scheme

The website uses a modern gradient color scheme:
- **Primary**: #667eea (Purple-Blue)
- **Secondary**: #764ba2 (Deep Purple)
- **Accent**: #f5576c (Pink-Red)
- **Background**: #f8f9fa (Light Gray)

## Responsive Breakpoints

- **Desktop**: Full layout with multi-column grids
- **Tablet** (≤768px): Adjusted spacing and single-column on some sections
- **Mobile** (≤480px): Optimized for small screens with full-width layouts

## Getting Started

1. Clone this repository
2. Open `index.html` in your browser
3. Customize the content with your own information
4. Deploy to your hosting platform (GitHub Pages, Netlify, Vercel, etc.)

## Deployment

This portfolio can be easily deployed on:

- **GitHub Pages** - Enable in repository settings
- **Netlify** - Drag and drop deployment
- **Vercel** - One-click deployment
- **Traditional Hosting** - Upload files to any web server
